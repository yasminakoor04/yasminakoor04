## 📁 Featured Projects

### 📊 Predicting Exercise Intensity from Smartwatch Data (Bachelor's Thesis)
* Engineered an end-to-end multi-sensor time-series data alignment pipeline using InfluxDB, R Shiny, and Python/Dash.
* Processed raw data ingestion from ActiGraph, EmotiBit, and Bangle.js hardware to evaluate machine learning feasibility against clinical ground truth calorimetry.
* Implemented Leave-One-Subject-Out (LOSO) cross-validation with Random Forest models to accurately predict Metabolic Equivalents of Task (METs).

### 🌱 IoT Environmental Monitoring System
* Engineered a real-time environmental sensing device using a Raspberry Pi Pico programmed in MicroPython.
* Interfaced hardware via GPIO pins, extracting temperature and humidity data from a DHT11 sensor.
* Implemented remote data transmission over Wi-Fi using the MQTT protocol, publishing telemetry to an Adafruit IO dashboard.
* Designed the physical circuit and logic loops, integrating a tilt switch and LED indicators for hardware feedback.
